# GameplayAbilities 回合制改造方案

> 本文为改造**方案**（先定方案、后实施）。目标是参考开源项目
> [BinaryBard996/TurnBasedSample](https://github.com/BinaryBard996/TurnBasedSample)
> 及其[博客说明](https://binarybard996.github.io/BinaryBardBlog/posts/turn-based-gas/)，
> 把本项目内的 `GameplayAbilities` 插件改造成**支持回合制**的版本。
>
> - 引擎基线：UE **5.8**（参考方案原针对 5.6/5.7，实施时需做少量 API 适配）
> - 项目插件：`GameWork/Plugins/GameplayAbilities`
> - 配套记录：`源码修改记录.md`（已存在 `GAS_MOD_01~04` 改动）

---

## 1. 背景与目标

### 1.1 问题

GAS 原生的 `GameplayEffect`（GE）在**持续时间、周期触发、冷却**等机制上，全部依赖
**世界时间驱动的 `FTimerManager`**（`GameplayEffect.cpp` 中通过 `SetTimer` 注册）：

| 机制 | 原生实现 | 回合制期望 |
|------|---------|-----------|
| Duration（持续时间） | 注册秒数 Timer，到期移除 GE | 持续 N **个回合** |
| Period（周期触发） | Looping Timer，按秒间隔重复 | 每 N **个回合**触发一次 |
| Cooldown（冷却） | 本质是带 Duration 的 GE | 冷却 N **个回合** |

回合制游戏需要这些效果基于**回合数**而非秒数推进。

### 1.2 目标

1. 让 `Duration`、`Period`、`Cooldown` 的**时间单位从"秒"切换为"回合"**；
2. 通过**手动调用 `TickTurn`** 作为回合推进的唯一入口；
3. **不改动 GE 的配置方式**（资产配置方式与实时制完全一致，仅语义变化）；
4. 支持**即时制 ↔ 回合制运行时动态切换**，保留 GAS 原有全部功能；
5. 所有改动沿用项目既有 **`GAS_MOD_xx` + 装饰线包裹** 标记规范。

## 2. 参考方案概述（TurnBasedSample）

参考方案核心思路：**用自定义的回合 Timer 管理器，替换 GE 中使用的实时 Timer**。

| 部分 | 内容 |
|------|------|
| 1. 新增 `FAbilityTimerManager` | 继承 `FTimerManager`，为每个 ASC 维护一个回合计时容器 |
| 2. 修改 `AbilitySystemGlobals` | 全局持有并管理 `AbilityTimerManager` |
| 3. 修改 `AbilitySystemComponent` | 新增 `bTurnBased` 回合开关 |
| 4. 修改 `GameplayEffect.cpp` | 改 `GetTimeRemaining`、Duration Timer、Period Timer |
| 5. 修改 `AbilitySystemBlueprintLibrary` | 新增蓝图可调用的 `TickTurn` 接口 |

所有改动均用注释 `// TurnBased Support` / `// ~TurnBased Support` 包裹标记。

## 4. 改造方案设计

### 4.0 标记与编号规划

沿用既有规范（装饰线 + `START`/`END` + 修改前/后对比）。新增改动编号顺延：

| 编号 | 位置 | 内容 |
|------|------|------|
| 新增文件 | `AbilityTimerManager.h/.cpp` | 全新文件，不打 `GAS_MOD`（整体即新增） |
| `GAS_MOD_05` | `AbilitySystemGlobals.h/.cpp` | 全局持有 `FAbilityTimerManager` |
| `GAS_MOD_06` | `AbilitySystemComponent.h/.cpp` | 新增 `bTurnBased` 回合开关 |

### 4.1 新增 `FAbilityTimerManager`（核心）

**文件**：`Public/AbilityTimerManager.h` + `Private/AbilityTimerManager.cpp`（新增）

```cpp
// 每个 ASC 的回合计时容器
struct FAbilityTimerContainer
{
    int32 Turn = 0;                       // 当前回合数
    TArray<FTimerHandle> TimerHandles;    // 该 ASC 下所有按回合推进的 Timer
};

// 回合 Timer 管理器：继承实时 FTimerManager，叠加"回合驱动"能力
class FAbilityTimerManager : public FTimerManager
{
public:
    // 推进某 ASC 的回合（Delta 步进）
    void TickTurn(UAbilitySystemComponent* ASC, int32 Delta = 1);

    // 替代 FTimerManager::SetTimer —— 把 Timer 注册进回合容器
    void SetAbilityTimer(UAbilitySystemComponent* ASC, FTimerHandle& OutHandle,
                         const FTimerDelegate& Delegate, float Rate /*回合数*/,
                         bool bLoop, float FirstDelay = -1.f);

    // 查询某 Timer 剩余回合数
    float GetAbilityTimerRemaining(UAbilitySystemComponent* ASC, FTimerHandle& Handle);

    // 查询某 ASC 当前回合数
    int32 GetAbilityCurrentTurn(const UAbilitySystemComponent* ASC) const;

    // 移除 ASC 的回合 Timer
    void RemoveAbilityTimer(UAbilitySystemComponent* ASC, FTimerHandle& Handle);

private:
    TMap<TWeakObjectPtr<UAbilitySystemComponent>, FAbilityTimerContainer> AbilityTimerContainers;
    FAbilityTimerContainer& GetAbilityTimerContainer(UAbilitySystemComponent* ASC);
};
```

**`TickTurn` 核心逻辑**（回合推进，等价于实时版 `FTimerManager::Tick`）：

```cpp
void FAbilityTimerManager::TickTurn(UAbilitySystemComponent* ASC, int32 Delta)
{
    FAbilityTimerContainer& Container = GetAbilityTimerContainer(ASC);
    for (int32 Step = 0; Step < Delta; ++Step)
    {
        Container.Turn++;                        // 当前回合统一由容器维护

        TArray<FTimerHandle> ToRemove;
        for (FTimerHandle& Handle : Container.TimerHandles)
        {
            FTimerData* Data = FindTimer(Handle);
            if (!Data) { ToRemove.Emplace(Handle); continue; }

            if (Data->ExpireTime <= Container.Turn)   // 到期
            {
                // 执行委托（Duration 到期 / Period 触发）
                if (const FTimerDelegate* Func = Data->TimerDelegate.VariantDelegate.TryGet<FTimerDelegate>())
                {
                    if (Func->IsBound()) Func->Execute();
                }

                if (Data->bLoop)
                    Data->ExpireTime = Container.Turn + Data->Rate;  // 循环：顺延
                else
                    ToRemove.Emplace(Handle);                         // 一次性：移除
            }
        }
        for (FTimerHandle& Handle : ToRemove)
        {
            RemoveAbilityTimer(ASC, Handle);
            ClearTimer(Handle);
        }
    }
}
```

**要点**：`Duration` 语义为 `ExpireTime = 起始回合 + Rate`；`Period` 用 `bLoop=true` 每 `Rate` 回合触发一次。

### 4.2 `AbilitySystemGlobals`（`GAS_MOD_05`）

新增全局单例式访问与生命周期清理：

```cpp
// AbilitySystemGlobals.h
public:
    FAbilityTimerManager& GetAbilityTimerManager();
    void DestroyAbilityTimerManager();
private:
    FAbilityTimerManager* AbilityTimerManager = nullptr;
```

- `GetAbilityTimerManager()`：懒加载创建，后续统一从此获取。
- `FinishDestroy()`：调用 `DestroyAbilityTimerManager()` 释放，防止泄漏。
- 注意：`FAbilityTimerManager` 是 `FTimerManager` 子类，持有 `UGameInstance` 引用时需正确处理生命周期。

### 4.3 `AbilitySystemComponent`（`GAS_MOD_06`）

```cpp
// AbilitySystemComponent.h
protected:
    UPROPERTY(EditAnywhere, Category = "TurnBased")
    bool bTurnBased = false;          // 是否回合制（默认关闭，保持原行为）

public:
    UFUNCTION(BlueprintCallable, Category = "TurnBased")
    bool IsTurnBased() const { return bTurnBased; }

    UFUNCTION(BlueprintCallable, Category = "TurnBased")
    void SetTurnBasedEnabled(bool bEnabled = false) { bTurnBased = bEnabled; }
```

**要点**：`bTurnBased` 仅作为"该 ASC 是否回合制"的开关。当前回合数统一由 `FAbilityTimerManager` 内部的 `FAbilityTimerContainer::Turn` 维护（通过 `GetAbilityCurrentTurn` 查询），ASC 上不再冗余保存 `CurrentTurn`，避免两份计数不一致。

### 4.4 `GameplayEffect.cpp`（`GAS_MOD_07`）

三处改动，均在原 `SetTimer`/`GetTimeRemaining` 处按 `IsTurnBased()` 分支：

#### (a) `FActiveGameplayEffect::GetTimeRemaining`

```cpp
float FActiveGameplayEffect::GetTimeRemaining(float WorldTime) const
{
    if (ASC && ASC->IsTurnBased())
    {
        FAbilityTimerManager& Mgr = UAbilitySystemGlobals::Get().GetAbilityTimerManager();
        const float CurTurn = (float)Mgr.GetAbilityCurrentTurn(ASC);
        const float Duration = GetDuration();
        return (Duration == INFINITE_DURATION) ? -1.f : Duration - (CurTurn - StartWorldTime);
    }
    // 实时分支：原逻辑不变
    const float Duration = GetDuration();
    return (Duration == INFINITE_DURATION) ? -1.f : Duration - (WorldTime - StartWorldTime);
}
```

> 回合制下 `StartWorldTime` 被语义化为"GE 开始时的回合数"，需要在本分支启用时正确记录。

#### (b) Duration Timer 注册（`GameplayEffect.cpp` ~4496）

```cpp
FTimerDelegate Delegate = FTimerDelegate::CreateUObject(Owner, &UAbilitySystemComponent::CheckDurationExpired, AppliedActiveGE->Handle);
if (!Owner->IsTurnBased())
{
    FTimerManager& TimerManager = Owner->GetWorld()->GetTimerManager();
    TimerManager.SetTimer(AppliedActiveGE->DurationHandle, Delegate, FinalDuration, false);
}
else
{
    FAbilityTimerManager& Mgr = UAbilitySystemGlobals::Get().GetAbilityTimerManager();
    Mgr.SetAbilityTimer(Owner, AppliedActiveGE->DurationHandle, Delegate, FinalDuration, false);
}
```

#### (c) Period Timer 注册（`GameplayEffect.cpp` ~4515 / 4663）

```cpp
FTimerDelegate Delegate = FTimerDelegate::CreateUObject(Owner, &UAbilitySystemComponent::ExecutePeriodicEffect, AppliedActiveGE->Handle);
if (!Owner->IsTurnBased())
{
    FTimerManager& TimerManager = Owner->GetWorld()->GetTimerManager();
    if (AppliedEffectSpec.Def->bExecutePeriodicEffectOnApplication)
        TimerManager.SetTimerForNextTick(Delegate);
    TimerManager.SetTimer(AppliedActiveGE->PeriodHandle, Delegate, AppliedEffectSpec.GetPeriod(), true);
}
else
{
    FAbilityTimerManager& Mgr = UAbilitySystemGlobals::Get().GetAbilityTimerManager();
    if (AppliedEffectSpec.Def->bExecutePeriodicEffectOnApplication)
        Mgr.SetTimerForNextTick(Delegate);
    Mgr.SetAbilityTimer(Owner, AppliedActiveGE->PeriodHandle, Delegate, AppliedEffectSpec.GetPeriod(), true);
}
```

**同步点**：Timer 清理（`~4925`、`~5412` 的 `ClearTimer`）也要在回合制分支下走 `RemoveAbilityTimer`，否则回合容器会残留无效句柄。

### 4.5 `AbilitySystemBlueprintLibrary`（`GAS_MOD_08`）

新增蓝图入口，作为回合推进唯一外部接口：

```cpp
// AbilitySystemBlueprintLibrary.h
UFUNCTION(BlueprintCallable, Category = "Ability|TurnBased")
static void TickTurn(UAbilitySystemComponent* AbilitySystemComponent, int32 Delta = 1);

// AbilitySystemBlueprintLibrary.cpp
void UAbilitySystemBlueprintLibrary::TickTurn(UAbilitySystemComponent* ASC, int32 Delta)
{
    if (!ASC) return;
    UAbilitySystemGlobals::Get().GetAbilityTimerManager().TickTurn(ASC, Delta);
}
```

## 5. 使用方式（改造完成后的玩法侧）

1. 在 ASC 默认属性中把 `bTurnBased` 勾选为 `true`（或用 `SetTurnBasedEnabled(true)`）。
2. GE 资产照常配置，语义变为：
   - `Duration = 1.0` → 持续 1 回合
   - `Period = 2.0` → 每 2 回合触发一次
3. 在角色/全局回合管理器里，每个回合开始（或结束）时调用：
   ```cpp
   UAbilitySystemBlueprintLibrary::TickTurn(ASC, 1);
   ```
4. 需要时可用 `SetTurnBasedEnabled(false)` 切回实时制（探索态实时、战斗态回合制）。

## 6. UE 5.8 适配注意（相对 5.6/5.7）

| 关注点 | 说明 |
|--------|------|
| `FTimerManager` API | 5.8 的 `FTimerManager::SetTimer`/`SetTimerForNextTick`/`FindTimer` 签名可能与 5.6/5.7 有差异，需以引擎实际声明为准 |
| `FTimerData` 结构 | `VariantDelegate`/`TimerDelegate` 内部表示可能变化，读取 `ExpireTime`/`bLoop`/`Rate` 字段时需核对 |
| 网络复制 | 回合数由 `FAbilityTimerManager` 在权威端维护，不随 ASC 复制；客户端如需回合表现需另行同步 |
| 预测 | 回合制下预测路径（`bInvokePredictedEffects`）与实时 Timer 的交互需额外验证 |
| 与 `GAS_MOD_03` 的关系 | 本项目 `GAS_MOD_03` 已修 StackOverflow；回合制的"Duration=回合数"仍复用原 Stack/Overflow 逻辑，二者不冲突 |

## 7. 与既有 `GAS_MOD_01~04` 的兼容性

- `GAS_MOD_01/02`（GameplayCue N*N 修复）在 Cue 触发层，回合改动在 Timer 层，**互不影响**。
- `GAS_MOD_03`（StackOverflow 边界）在 `HandleActiveGameplayEffectStackOverflow`，回合改动不涉及该函数，**无冲突**。
- `GAS_MOD_04`（PRAGMA 屏蔽）在 `AbilitySystemBlueprintLibrary.cpp`，`GAS_MOD_08` 也在该文件但位置不同（新增静态函数），**可共存**。
- 实施时务必**保留** `GAS_MOD_01~04`，新增改动从 `GAS_MOD_05` 起编号，避免覆盖。

## 9. 风险与注意事项

- **Timer 句柄双轨**：回合 Timer 同时存在于 `FTimerManager`（父类）与回合容器中，清理时必须两边同步，否则会悬空/泄漏。
- **`StartWorldTime` 语义重载**：回合制下被当作"起始回合"使用，需在启用回合制时正确写入，否则 `GetTimeRemaining` 计算错误。
- **世界时间兜底**：`TickTurn` 未按时调用时，回合 Timer 不会自动到期（符合预期，但需玩法侧保证推进）。
- **动态切换**：从回合制切回实时制时，已在回合容器里的 Timer 需迁移或清理，避免双系统同时驱动同一 GE。
- **升级引擎**：若后续引擎升级回刷插件，`GAS_MOD_05~08` 会随 `TurnBased Support` 注释一并被覆盖，需重新合并。

## 10. 结论

本方案以 **TurnBasedSample 的低侵入思路**为基础（不改 GE 配置、只替换底层 Timer 驱动），落地到本项目 UE 5.8 的 `GameplayAbilities` 插件，并以项目既有的 `GAS_MOD_xx` 标记体系管理改动。核心交付：`FAbilityTimerManager`（回合 Timer 管理器，内含回合计数）+ `bTurnBased`（ASC 回合开关）+ 三处 GE Timer 分支 + 蓝图 `TickTurn` 入口。实施前请以第 6 节的 5.8 适配项逐项核对引擎 API。
