# 使用说明

## 如何触发

在对话中提及以下关键词或场景时，会自动加载此技能：

### 直接触发
- "帮我写一篇关于 XXX 的技术文章"
- "分析这段源码并写文章"
- "写技术文章"
- "tech article" / "technical writing"

### 间接触发
- 你正在准备系列化技术内容
- 你需要优化现有文章的结构
- 你想要设计文章大纲

## 使用场景示例

### 场景一：从零起草一篇技术文章
```
用户：帮我写一篇关于 UE5 Enhanced Input 系统的技术文章
AI：加载 tech-article-writer 技能 → 按五段式设计大纲 → 逐段撰写
```

### 场景二：分析源码后写成文章
```
用户：分析 UGameplayAbility::ActivateAbility 的实现，给我写一篇文章
AI：分析源码 → 提取核心概念 → 设计思考点 → 撰写文章
```

### 场景三：规划文章系列
```
用户：我想写一个 UE5 Gameplay Ability System 系列文章，帮我规划
AI：设计系列目录 → 统一标题格式 → 规划每篇焦点 → 预计篇数
```

### 场景四：优化已有文章
```
用户：帮我看看这篇技术文章有什么可以改进的
AI：对照质量检查清单 → 指出结构问题 → 建议改进方案
```

## 输出内容

每次输出包含三个部分：
1. **文章大纲**：确认方向和结构
2. **正文**：按五段式展开
3. **质量评估**：附检查清单自查结果
