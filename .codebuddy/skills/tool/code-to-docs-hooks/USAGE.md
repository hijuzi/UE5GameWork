# code-to-docs-hooks 使用指南

## 功能

自动化文档生命周期——安装/移除项目级钩子，自动触发文档加载和更新提醒。

## 使用方式

```
"安装文档自动更新钩子"
"移除文档钩子"
```

## 两个钩子

| 钩子 | 触发时机 | 作用 |
|------|---------|------|
| **SessionStart** | 每次打开编程会话 | 自动运行 `code-to-docs-digest` 加载文档上下文 |
| **PostToolUse** | Git 提交后 | 提醒是否需要 `code-to-docs-update` 同步文档 |

## 使用示例

### 示例 1：安装自动化

> **你**: "帮我设置文档自动更新"

> **AI**: 在 `.claude/settings.json` 写入两个钩子配置，此后每次打开会话自动注入文档上下文，Git 提交后提示更新。

### 示例 2：移除自动化

> **你**: "不需要自动文档了，关掉"

> **AI**: 从 `.claude/settings.json` 移除 code-to-docs 相关钩子，其他钩子不受影响。

## 配置

设置环境变量覆盖默认文档路径：

```bash
export CODE_TO_DOCS_VAULT="./my-custom-vault/"
```

## 适用场景

- 团队项目希望开发者每次编码前自动了解项目状态
- 不想手动记住更新文档
- 临时团队或短期项目（完事后 teardown 清理）
