## 使用方式（三种方法）

### 1. 自动匹配（最常用）
直接说需求，AI 自动加载技能：
```
"帮我做一个血量同步"              → networking-and-replication
"场景太暗怎么调"                  → lighting-and-lumen
```

### 2. 对话中指定
```
"用 gameplay-ability-system 技能，做一个火球技能"
```

### 3. 直接打开 USAGE.md
点击上方表格链接，查看每个技能的详细用法和代码示例。
