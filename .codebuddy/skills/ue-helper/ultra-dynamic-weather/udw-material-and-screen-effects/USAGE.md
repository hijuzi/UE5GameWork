# udw-material-and-screen-effects 使用指南

## 功能

材质响应天气、屏幕水滴效果、霜冻/结冰、彩虹效果。

## 使用方式

```
"下雨时地面怎么产生水坑？"
"屏幕上加水滴和镜头模糊"
"雨后彩虹怎么出现？"
```

## 使用示例

> **你**: "下雨时路面材质变湿，有水滴"

> **AI**: 材质中引用 UDW 的 `Wetness` 参数 → `Puddle Amount` 和 `Ripple` 效果随雨量变化。

> **你**: "第一人称视角屏幕下雨滴"

> **AI**: UDW → Screen Effects → `Enable Rain Drops = true` → 调整大小和透明度。

## 屏幕效果

| 效果 | 说明 |
|------|------|
| Rain Drops | 屏幕水滴 |
| Frost | 霜冻边框 |
| Rainbow | 雨后彩虹 |
| Wetness | 材质湿滑度 |

## 适用场景

- 沉浸式天气体验
- 第一/第三人称屏幕效果
