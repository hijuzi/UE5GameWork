# udw-particles-lightning-wind-sounds 使用指南

## 功能

控制雨雪粒子、闪电、风效、天气音效。

## 使用方式

```
"雨滴粒子太少了，怎么调？"
"加闪电频繁一点"
"风声和雨声协调不了"
```

## 使用示例

> **你**: "暴雨加密集闪电，雷声要大"

> **AI**: `Rain Particle Count = 5000` → `Lightning Frequency = 3.0`（每秒 3 次）→ `Thunder Volume = 1.0`。

> **你**: "刮风声和雨声一起播放，层次分明"

> **AI**: Wind Sound → `Volume = 0.8` → Rain Sound → `Volume = 0.6` → 设置不同的衰减曲线。

## 核心效果

| 效果 | 控制 |
|------|------|
| Rain Particles | 雨滴密度、速度、大小 |
| Snow Particles | 雪花密度、飘落速度 |
| Lightning | 频率、亮度、颜色 |
| Wind | 强度、方向、音效 |
| Weather Sounds | 雨声/风声混合 |

## 适用场景

- 暴风雨效果
- 极端天气氛围
