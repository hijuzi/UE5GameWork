# blueprint-fundamentals 使用指南

## 功能

理解蓝图作为 UE 可视化脚本和资产类系统 —— 蓝图类、UBlueprint 资产 vs UBlueprintGeneratedClass 运行时类、图表类型、变量和组件。

## 使用方式

```
"解释一下蓝图和 C++ 在 UE 里是什么关系？"
"什么时候该用蓝图，什么时候该用 C++？"
"蓝图编译错误怎么排查？"
```

## 使用示例

### 示例 1：C++ 基类 + 蓝图子类工作流

> **你**: "C++ 写基类 ABossBase，蓝图创建 BP_DragonBoss 子类，这个模式怎么工作？"

> **AI**: C++ 定义核心逻辑和数据（碰撞、血量、AI），蓝图子类设置具体数值（模型、动画、生命值）、连接事件图表、配置组件。

### 示例 2：变量 vs 组件

> **你**: "这个功能放蓝图的变量里还是用组件实现？"

> **AI**: 简单数据用变量（float Speed），复杂可复用行为用组件（UHealthComponent）。

### 示例 3：图表类型选择

> **你**: "蓝图里有 EventGraph 还有 Functions，有什么区别？"

> **AI**: EventGraph 是事件驱动（BeginPlay、Tick），Functions 是被调用执行（可复用、无延迟节点）。

## 分工建议

| 放 C++ | 放蓝图 |
|--------|--------|
| 性能敏感逻辑 | 视觉/表现调整 |
| 网络复制核心 | 事件绑定和串联 |
| 复杂算法 | 数值配置和调试 |
| 引擎级系统 | 快速原型和迭代 |

## 适用场景

- 梳理蓝图和 C++ 分工
- 设计跨 C++/蓝图的类层次
- 解释蓝图逻辑如何映射到底层 UObject 模型
- 调试蓝图编译和类关系问题
