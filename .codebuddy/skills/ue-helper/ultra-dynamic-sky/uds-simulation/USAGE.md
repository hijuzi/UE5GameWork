# uds-simulation 使用指南

## 功能

真实天文模拟 —— 经纬度、时区、太阳/月亮真实位置计算。

## 使用方式

```
"设置地点为北京经纬度"
"太阳位置能按真实天文数据吗？"
```

## 使用示例

> **你**: "模拟北京(39.9°N, 116.4°E)的天空"

> **AI**: UDS 设置 `Use Location = true` → Latitude: 39.9, Longitude: 116.4 → Time Zone: +8。

> **你**: "冬天太阳角度更低，怎么模拟？"

> **AI**: 启用真实天文模拟后，日期会自动影响太阳高度。

## 关键参数

| 参数 | 说明 |
|------|------|
| Latitude | 纬度 (-90~90) |
| Longitude | 经度 (-180~180) |
| Time Zone | 时区偏移 |
| Day of Year | 一年中的第几天 |

## 适用场景

- 建筑可视化
- 特定地点/日期模拟
