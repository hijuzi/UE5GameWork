# uds-setup-and-modes 使用指南

## 功能

安装配置 Ultra Dynamic Sky (UDS) 插件，选择天空模式（Dynamic / Static / 2D）。

## 使用方式

```
"帮我安装 UDS 插件"
"静态天空和动态天空有什么不同？"
```

## 使用示例

> **你**: "我想用 UDS 做一个动态昼夜天空"

> **AI**: 从插件文件夹安装 UDS → 在关卡中放置 UDS 蓝图 → 选择 Dynamic 模式 → 设置时间系统、云层、光照。

## 天空模式

| 模式 | 特点 |
|------|------|
| Dynamic | 实时昼夜变化、动态云 |
| Static | 固定时间、高性能 |
| 2D | 移动端优化、简化效果 |

## 适用场景

- UDS 初始安装和配置
- 天空模式选择
