# uds-sun-moon-stars 使用指南

## 功能

控制太阳/月亮/星星/极光 —— 大小、亮度、颜色、位置。

## 使用方式

```
"月亮太大了，怎么调小？"
"加入星空和极光效果？"
```

## 使用示例

> **你**: "月亮大小缩小 50%，加一点暖色调"

> **AI**: UDS → Moon → `Moon Scale = 0.5` → Moon Color 设为淡金色。

> **你**: "在高纬度场景加极光"

> **AI**: UDS → Auroras → `Enable Auroras = true` → 调整亮度。

## 核心元素

| 元素 | 可控参数 |
|------|---------|
| Sun | 颜色、强度、大小、光晕 |
| Moon | 大小、相位、颜色 |
| Stars | 密度、亮度、闪烁 |
| Aurora | 颜色、强度、形状 |

## 适用场景

- 夜空效果
- 极光氛围
