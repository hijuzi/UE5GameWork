# uds-lighting-and-shadows 使用指南

## 功能

UDS 光照和阴影 —— Sky Light 强度、阴影质量、曝光控制、间接光照。

## 使用方式

```
"场景太暗了，但不想调时间"
"阴影锯齿怎么减少？"
```

## 使用示例

> **你**: "正午时分天空太亮，角色背光面太黑"

> **AI**: UDS → Lighting → 增加 `Sky Light Intensity` 提高环境补光 → 调节 `Shadow Sharpness`。

> **你**: "动态天气切换时曝光不自然"

> **AI**: UDS → 启用 `Auto Exposure` 平滑过渡 → 调整 `Exposure Compensation`。

## 关键参数

| 参数 | 效果 |
|------|------|
| Sun Intensity | 太阳光强度 |
| Sky Light Intensity | 天空环境光 |
| Shadow Sharpness | 阴影边缘锐度 |
| Exposure Compensation | 曝光补偿 |

## 适用场景

- 明暗场景光照
- 阴影质量优化
